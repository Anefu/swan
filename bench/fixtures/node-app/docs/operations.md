# Operations guide

## 1. Ingest (limits)

The ingest module batches CSV exports before handing them to the next stage. It keeps at most 900 items in flight, logs a structured line for each rejected item, and exposes counters for throughput and errors. When an upstream call fails it backs off for 9 seconds, doubling up to a minute, and gives up after 11 attempts. Configuration lives in environment variables prefixed with INGEST_, and every option has a safe default.
