# Architecture

## 1. Ingest (limits)

The ingest module retries CSV exports before handing them to the next stage. It keeps at most 200 items in flight, logs a structured line for each rejected item, and exposes counters for throughput and errors. When an upstream call fails it backs off for 2 seconds, doubling up to a minute, and gives up after 4 attempts. Configuration lives in environment variables prefixed with INGEST_, and every option has a safe default.
